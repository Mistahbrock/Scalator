# Scalator

A Graphical tool for crating circular scales for knob in GUI's, I made this for building VST GUI Plugins

This tool was build using Calude Code, as I am not really a coder, and for now i't OS X only
feel free to make it Windows or Linux, I have made it to ease my own plugin building life :)
